# Valora

eCommerce platform built with MongoDB, Express, React, Node.js, and Redux Toolkit.

Maintained and updated by **Faramarz saidmohammadi**.

## Features

- Product catalog with search, pagination, and filtering
- Product details with ratings and reviews
- Cart and checkout flow
- PayPal payment integration
- User profile and order history
- Admin management for users, products, and orders

## Environment Variables

Create `.env` in project root:

```env
NODE_ENV=development
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
PAYPAL_CLIENT_ID=your_paypal_client_id
PAGINATION_LIMIT=8
```

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
